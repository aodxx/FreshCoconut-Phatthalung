# Brand Foundation

## Current Direction

แบรนด์ควรสื่อ:

- สด
- สะอาด
- จริงใจ
- เป็นร้านท้องถิ่นที่ไว้ใจได้
- ดูเป็นมืออาชีพโดยไม่ดูห่างเหิน

## Visual Direction

ใช้ภาพและองค์ประกอบที่เชื่อมโยงกับมะพร้าวจริง สวน วัตถุดิบสด และการเตรียมสินค้าจริงเมื่อเหมาะสม หลีกเลี่ยงภาพลักษณ์การ์ตูน/น่ารักแบบ generic ที่ทำให้แบรนด์ดูเหมือนสินค้าทั่วไป
