# Business Rules

เอกสารนี้เก็บหลักการที่ถือเป็นกติกาธุรกิจปัจจุบัน

## Confirmed

- สินค้าหลักคือมะพร้าวขูดขาวสด
- ขูดเฉพาะเนื้อสีขาว
- ใช้มาตรฐานความละเอียดเดียวในระยะแรก
- ไม่ทำน้ำกะทิในระยะเริ่มต้น
- ขูดสดตามออเดอร์/รอบส่ง
- หน่วยสั่งซื้อเป็นกิโลกรัม
- ลูกค้า 3 กลุ่ม: ครัวเรือน, ร้านค้า/ธุรกิจ, งานบุญ/งานพิธี/งานชุมชน
- ส่งปกติตามรอบและเส้นทางของร้านฟรีในช่วงเริ่มต้น
- สั่งนอกเวลารอบปกติได้ โดยสามารถเสนอ Special Delivery แบบมีค่าใช้จ่าย
- ไม่ใช้ “กิโลกรัมสูงสุดต่อรอบ” เป็นกฎหลัก
- การรับออเดอร์ต้องสอดคล้องกับแผนการผลิตและจัดส่งจริง

## Rules for the Future System

- ห้ามแสดงเวลาที่ระบบรู้ว่าไม่สามารถทำได้
- เมื่อรอบที่เหมาะสมออกไปแล้ว ให้เสนอรอบถัดไปหรือการส่งพิเศษตามสิทธิ์
- ราคาต้องมาจากข้อมูลกลาง ไม่ฝังตัวเลขไว้ในหน้าลูกค้า
- ค่าจัดส่งต้องมาจากกติกาที่ตั้งค่าได้
- ข้อความสถานะต้องสื่อความหมายที่ตรงกับสถานะจริง
- การตั้งค่าหลังบ้านต้องไม่ต้องแก้ source code

## Not Yet Chosen Values

ตัวเลขและนโยบายต่อไปนี้ยังไม่กำหนด แต่ความสามารถในการตั้งค่าถือเป็น System Requirement:

- ราคาสินค้า
- ราคากลุ่มลูกค้า/ปริมาณ หากเปิดใช้
- เวลาและจำนวนรอบส่ง
- cutoff
- ค่าจัดส่งพิเศษ
- วิธีคำนวณค่าจัดส่ง
- ระยะทางสูงสุด
- เงื่อนไขฟรีส่ง
- โปรโมชั่น
