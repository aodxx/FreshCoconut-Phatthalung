# Customer Journey

## เป้าหมาย

ลูกค้าต้องสั่งง่าย เข้าใจสถานะได้เอง และไม่ต้องทักถามซ้ำว่าออเดอร์ถึงไหนแล้ว

## Journey หลัก

1. ลูกค้าเข้าจาก LINE OA, QR, การบอกต่อ, Facebook หรือช่องทางอื่น
2. เห็นข้อเสนอสินค้ามะพร้าวขูดขาวสดและปุ่มหลักสำหรับสั่งซื้อ
3. เลือกจำนวนเป็นกิโลกรัม
4. ระบุวันที่/เวลาที่ต้องการใช้สินค้า หรือเลือกว่าส่งรอบไหนก็ได้
5. ระบบหารอบและเส้นทางที่เหมาะสม
6. หากรอบปกติที่เหมาะสมออกไปแล้ว ให้เสนอรอบถัดไป
7. หากลูกค้าต้องการเวลาพิเศษ ให้เสนอ Special Delivery ที่มีค่าจัดส่งตามการตั้งค่า
8. ลูกค้ายืนยันออเดอร์
9. ระบบแจ้งว่า “รับออเดอร์แล้ว” เมื่อมีแผนรองรับจริง
10. ลูกค้าติดตามสถานะสำคัญ: รับออเดอร์แล้ว → รอเตรียมตามรอบ → กำลังขูด → ชั่งและแพ็ก → กำลังส่ง → ส่งถึงแล้ว
11. หลังส่งสำเร็จ ลูกค้าสามารถ “สั่งอีกครั้ง” ได้ง่าย

## หลัก UX

- ใช้ภาษาไทยธรรมชาติ เข้าใจง่าย
- ไม่ใช้คำเทคนิคของระบบ เช่น Checkout, Processing, Fulfilled
- ไม่บังคับลูกค้าเข้าใจกระบวนการหลังบ้าน
- แจ้งเฉพาะเหตุการณ์สำคัญ ไม่ส่งข้อความถี่เกินจำเป็น
- ถ้ารอบเช้าออกไปแล้ว ต้องบอกตามจริงและเสนอทางเลือก
