## Core Business Direction

- สินค้าหลัก: มะพร้าวขูดขาวสด
- ขูดเฉพาะเนื้อมะพร้าวสีขาว ไม่เอาเปลือกสีน้ำตาล
- มาตรฐานขนาด/ความละเอียดของการขูด ไม่เปิดให้ลูกค้าเลือกละเอียด/หยาบในระยะแรก
- ไม่ทำน้ำกะทิในแนวคิดเริ่มต้น
- ขูดสดตามออเดอร์/รอบส่ง ไม่ผลิตค้างจำนวนมาก
- หน่วยสั่งซื้อหลักเป็นกิโลกรัม
- ลูกค้า 3 กลุ่มหลัก: ครัวเรือน, ร้านค้า/ธุรกิจ, งานบุญ/งานพิธี/งานชุมชน
- จุดเตรียมและจัดส่ง: ตำบลโคกชะงาย อำเภอเมืองพัทลุง จังหวัดพัทลุง
- วัตถุดิบมาจากสวนของเจ้าของในอำเภอป่าพะยอม จังหวัดพัทลุง
- การส่งปกติตามรอบและเส้นทางของร้าน: ฟรีในช่วงเริ่มต้น
- ลูกค้าสั่งนอกเวลาได้ หากต้องการเวลาพิเศษให้รองรับการจัดส่งพิเศษแบบมีค่าจัดส่งตามกติกาที่เจ้าของตั้งค่า
- ระบบควรช่วยหารอบ/เส้นทางที่เหมาะสม ไม่ใช้จำนวนกิโลกรัมต่อรอบเป็นกฎหลัก
- ราคา รอบส่ง เส้นทาง ค่าจัดส่ง โปรโมชั่น และข้อความลูกค้า ต้องปรับได้จากระบบโดยไม่ต้องแก้โค้ด

## Important Rule

สิ่งที่เป็น **ความสามารถของระบบที่ควรปรับตั้งค่าได้** ให้ถือเป็น System Requirement ตั้งแต่ต้น แม้เจ้าของธุรกิจจะยังไม่ได้กำหนดค่าตัวเลขหรือกติกาจริง เช่น ราคา ค่าจัดส่ง รอบส่ง cutoff และพื้นที่บริการ

ส่วนค่าหรือกติกาที่เจ้าของยังไม่เลือก ให้บันทึกเป็น **Business Decision ที่รอการกำหนดค่า** ไม่ใช่เหตุผลในการตัดความสามารถออกจากระบบ
