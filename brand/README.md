# Brand Workspace

พื้นที่กลางสำหรับงานแบรนด์และ visual identity

## Asset Folders

- `logo/` — logo และ logo variations
- `profile/` — profile images
- `banner/` — cover/banner
- `line-oa/` — LINE OA visual assets / Rich Menu
- `product/` — product photography/illustration
- `packaging/` — packaging and labels
- `social/` — social media templates

ดูสถานะและ purpose ของแต่ละ asset ที่ `ASSET_MANIFEST.md`

งานภาพจริงจะเริ่มหลัง Brand Foundation ผ่านการทบทวนและกำหนด Brand Strategy แล้ว
