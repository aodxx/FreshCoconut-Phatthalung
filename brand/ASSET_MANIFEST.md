# Brand Asset Manifest

สถานะมาตรฐาน: `PLANNED` → `IN_PROGRESS` → `APPROVED` → `FINAL`

| Asset | Path | Purpose | Status |
|---|---|---|---|
| Logo | `brand/logo/` | เครื่องหมายหลักของแบรนด์ | PLANNED |
| Profile | `brand/profile/` | LINE OA / social profile | PLANNED |
| Banner | `brand/banner/` | LINE OA cover / social cover | PLANNED |
| LINE OA | `brand/line-oa/` | Rich Menu และภาพประกอบ LINE | PLANNED |
| Product | `brand/product/` | ภาพสินค้ามะพร้าวขูดขาวสด | PLANNED |
| Packaging | `brand/packaging/` | ฉลาก/ถุง/แพ็กเกจ | PLANNED |
| Social | `brand/social/` | Template สำหรับโพสต์ | PLANNED |

## File Rules

- ต้นฉบับที่ต้องแก้ไขต่อได้ ควรเก็บใน Google Drive
- ไฟล์ที่ผ่านการอนุมัติและใช้จริงควรมีสำเนา/metadata ใน GitHub
- ทุก asset ต้องระบุ purpose, status และ version เมื่อเริ่มผลิตจริง
- ห้ามถือภาพที่สร้างทดลองเป็น Final จนกว่าจะได้รับการยืนยัน
